# RAG 简介

RAG（Retrieval-Augmented Generation，检索增强生成）是一种让大语言模型
"开卷考试"的技术：回答问题前，先从外部知识库检索相关资料，再结合资料生成答案。

## 为什么需要 RAG

1. 知识截止：模型的训练数据有截止日期，无法知道之后发生的事。
2. 幻觉问题：模型不知道时会一本正经地编造，RAG 用真实资料约束它。
3. 私域知识：公司内部文档、个人笔记从未进入预训练，只能通过 RAG 注入。

## RAG 的三个阶段

- 索引阶段：文档切块（chunking）-> 向量化（embedding）-> 存入向量数据库。
- 检索阶段：用户问题向量化 -> 在向量库中找最相似的 top_k 个块。
- 生成阶段：把检索到的块拼进提示词，LLM 基于资料作答。

## RAG 的局限

检索错了，生成就错了——所谓"垃圾进，垃圾出"。
因此切块策略、embedding 模型质量、top_k 的选择都直接影响最终效果。
