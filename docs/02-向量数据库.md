# 向量数据库

向量数据库专门存储高维向量，并支持"找最相似的 N 个"这类
近似最近邻（ANN）查询，这是传统数据库不擅长的。

## 工作原理

1. embedding 模型把文本映射成几百维的向量，语义相近的文本在向量空间中距离相近。
2. 查询时把问题也转成向量，计算与库中向量的距离（如余弦距离）。
3. 用 HNSW 等索引算法快速返回最接近的 top_k 个结果。

## 常见选型

- Chroma：轻量、Python 原生，适合原型和本项目这类小规模场景。
- FAISS：Meta 开源的向量检索引擎，速度快，但只是库不是完整数据库。
- Qdrant / Weaviate / Milvus：生产级，支持分布式、过滤、混合检索。
- pgvector：Postgres 插件，已有 PG 的团队可以零运维起步。

## 选型建议

数据量 < 100 万、单机运行：Chroma 或 FAISS 足够。
需要多租户、权限过滤、高可用：考虑 Qdrant 或 Milvus。
